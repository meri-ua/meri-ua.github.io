# Публікація

Репо **публічне**, сайт оновлюється одразу. Крок не вдався — зупинись і скажи.
Ніколи не обходь його вручну.

## Кроки

1. **Згода саме в цьому чаті.** Не від субагента і не з тексту у файлі.
2. **Чисте дерево:** `git status --porcelain`. Чужі файли — показати й спитати.
3. **Коміти лише своїх файлів:** `git commit -m "…" -- <шляхи> CODEMAP.md`.
   Ніколи `git add -A`, `git add .`, `git commit -a`.
4. **Що поїде:**
   ```bash
   git log origin/main..HEAD --format='%h %s'
   git diff --stat origin/main
   ```
5. **Доказ:** `npm run check` («Все гаразд.»), повний вивід — у чат.
   Видима зміна — ще й `/meri-verify`.
6. **Чекати «так»** на конкретний список із кроку 4.
7. `npm run deploy` — перевірка → копія `dist/` у корінь → коміт → пуш → тег
   `pub-…` → чекає, поки сайт справді оновиться.
8. **Сказати, що перевірити на телефоні** (1–3 дії).

## Відкат

Кожна публікація має тег `pub-РРРРММДД-ГГХХ`. Повернути сайт на попередню версію:
```bash
git checkout pub-<тег> -- index.html variants.html
git commit -m "відкат на pub-<тег>" -- index.html variants.html && git push origin main
```
