# Meri.ua

Українські вертикальні серіали, які можна дивитися безкоштовно.
MVP-прототип першого етапу: каталог, рекомендації, вертикальний плеєр, монети за рекламу.

**Сайт:** https://meri-ua.github.io/ · порівняння дизайнів: https://meri-ua.github.io/variants.html

## Команди

| Команда | Що робить |
|---|---|
| `npm run build` | Збирає `src/` в одну програму `dist/index.html` |
| `npm run dev` | Збирає й відкриває на http://localhost:4174 |
| `npm run check` | Перевірка здоров'я — команда-доказ перед «готово» |
| `npm run map` | Оновлює карту коду `CODEMAP.md` |
| `npm run deploy` | Перевірка → коміт → пуш → чекає, поки оновиться сайт |

Потрібні Python 3 і Node.js (лише для перевірки синтаксису).

## Структура

```
src/
  index.html          каркас: куди збірка вклеює стилі, дані й код
  data/series.js      каталог серіалів, рекламодавці, пакети монет (вигадані)
  styles/             01-base.css (iOS-база), 02-variants.css (Liquid Glass, Cinema)
  scripts/core/       логіка; номер у назві файлу = порядок виконання
  web/                файли, що копіюються як є (variants.html)
tools/                build.py, check.sh, codemap.py, deploy.sh, scriptcheck.js
dist/                 зібрана програма (не в git)
index.html            опублікована копія dist/ — її віддає GitHub Pages
docs/slovnyk.md       словник термінів
prompts/              шаблони задач для Claude
CLAUDE.md             правила роботи над проєктом
CODEMAP.md            карта коду (будує скрипт)
```

## Що вміє застосунок

- **Для тебе** — вертикальна стрічка з рекомендаціями (жанри з історії, лайки, збережене, новинки).
- **Каталог** — пошук, жанри, вибір редакції, популярне, новинки, незалежні автори, AI Studio.
- **Медіатека** — продовження перегляду, збережене, ваші голоси.
- **Монети** — реклама (+5, до 30 на день, пауза 20 с), щоденний бонус, пакети (демо-оплата).
- **Профіль** — Meri+ (демо), оформлення, налаштування, історія, заявка для творців.
- **Плеєр** — свайп ↑/↓, пауза тапом, закриті серії (10 монет / реклама / Meri+), голосування після фіналу.

Відео поки симульовано анімованими сценами; сервера, акаунтів і справжніх платежів немає.
