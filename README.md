# Meri.ua — MVP

Прототип платформи українських вертикальних серіалів (етап 1: «безкоштовно через рекламу»).

## Запуск

```bash
python3 -m http.server 5173
```

Відкрити http://localhost:5173 (найкраще в мобільному режимі браузера).

## Що є

- **Для тебе** — вертикальна стрічка з рекомендаціями (жанри з історії, лайки, збережене, новинки).
- **Каталог** — пошук, жанри, популярне, новинки, незалежні автори, AI Studio.
- **Мої серіали** — продовження перегляду, збережене, ваші голоси.
- **Монети** — реклама (+5, до 30/день, пауза 20 с), щоденний бонус, пакети (демо-оплата).
- **Профіль** — Meri+ (демо), налаштування, історія, заявка для творців.
- Плеєр: свайп ↑/↓, пауза тапом, замкнені серії (10 монет / реклама / Meri+), голосування після фіналу сезону.

## Структура

- `data.js` — каталог серіалів, рекламодавці, пакети монет (вигадані).
- `app.js` — логіка, економіка (`CFG` на початку файлу), стан у localStorage.
- `styles.css` — стилі.

Відео поки симульовано анімованими сценами; бекенду, авторизації та реальних платежів немає.

## Дизайн

Три варіанти в стилі Apple (перемикаються в «Профіль → Оформлення» або через `?v=`):

- `ios` — iOS Classic: системні кольори, згруповані списки, синій акцент.
- `music` — Cinema: темний кінорежим, великі обкладинки, рожевий акцент.
- `glass` — Liquid Glass: скляні панелі, плаваючий таб-бар.

Порівняння поруч: http://localhost:5173/variants.html
