# Правила роботи над Meri.ua

Цей файл читає Claude на початку кожної сесії. Тут лише те, чого не видно з коду.

Meri.ua — платформа українських вертикальних серіалів. Перший етап:
«українські серіали, які можна дивитися безкоштовно» (монети за рекламу,
вертикальний плеєр, рекомендації). Студія, кабінет авторів і AI-виробництво —
пізніше, коли з'явиться аудиторія.

---

## Три залізні правила

### 1. Спершу задум — потім код

**Не писати код, доки я не сказав «так» на твій задум.**

| Тип задачі | Що робиш перед кодом |
|---|---|
| **Розвідка** (чи це взагалі можливо, тимчасовий код на викид) | 2–3 речення: що перевіряєш і як. Дочекайся кивка |
| **Точкова правка** (зміна в наявній системі з `CODEMAP.md`) | Уточнювальні питання → короткий опис у чаті → чекай згоди |
| **Нова система** (новий файл у `src/scripts/core/`, зміна структури) | Питання → 2–3 варіанти з чесними мінусами → опис по пунктах → чекай згоди |

Питання став **по одному**, не списком. Де можеш — давай варіанти на вибір.
«Просто» означає короткий задум, а не відсутність задуму.

### 2. Не казати «готово» без свіжого доказу

Перед будь-яким «працює / готово / полагодив»:

1. Назви команду, яка це доводить
2. Запусти її **зараз**, повністю
3. Прочитай увесь вивід, порахуй помилки
4. Якщо вивід не збігається із заявою — кажи, що насправді сталося
5. Тільки тоді заявляй — і покажи вивід

Наша команда-доказ:

```bash
npm run check
```

Вона перевіряє синтаксис кожного JS-файлу справжнім движком (Node), збирає
програму, розбирає зібрані `<script>` так, як браузер, звіряє автономність,
карту коду, дати за місцевим часом, секрети і що в `dist/` лише файли сайту.

**Стоп-сигнали:** «має працювати», «схоже, вийшло», «Готово!» до `npm run check`,
виправлений баг без відтвореного й зниклого симптому.

### 3. Перевіряй в браузері, а не лише збіркою

Якщо зміну **видно на екрані** — `npm run check` недостатньо:

1. Підняти прев'ю — конфіг `meri` у `.claude/launch.json` (збирає й роздає `dist/`, порт 4174)
2. Натиснути **саме те, що змінив** — по-справжньому
3. Подивитись консоль браузера на помилки
4. Перемкнути на **375×812 (iPhone)** — Meri живе в телефоні
5. Перевірити світлу і темну тему, якщо змінювався CSS
6. Показати мені знімок екрана

Окремо: чи не перекриває плаваючий таб-бар (Liquid Glass) останній блок
сторінки і кнопки стрічки «Для тебе». Покрокова інструкція — скіл `/meri-verify`.

## Вчи мене програмування

- **Нове слово — коротко пояснюй:** українською · англійський оригінал · одне
  речення «що це» · приклад із Meri. Один рядок, не лекція.
- **Записуй його в словник** `docs/slovnyk.md`, якщо його там ще нема.
- **Раз на завершену задачу — одне поняття з основ** на прикладі щойно зробленого, 3–5 речень.

## Що важливо знати про проєкт

- **`dist/` і `index.html` / `variants.html` у корені НЕ редагують.** Правлять
  `src/` → `npm run build`. Корінь заповнює `npm run deploy` (звідти GitHub Pages
  віддає сайт), `dist/` — збірка.
- **Порядок файлів у `src/scripts/core/` — це порядок виконання.** Усі файли
  вклеюються в один `<script>`, тож вони бачать змінні одне одного. Номери не міняти;
  новий файл — з номером у потрібному місці.
- **Перед читанням коду — `CODEMAP.md`.** Карту будує скрипт, руками не правити:
  після змін у коді — `npm run map`.
- **Економіка — в одному місці:** `CFG` у `src/scripts/core/01-config.js`
  (ціна серії, монети за рекламу, ліміт 30 реклам на день, пауза, ціна Meri+).
- **Каталог серіалів і рекламодавці — `src/data/series.js`.** Усі назви вигадані;
  справжні бренди чи людей без дозволу не додавати.
- **Дизайн:** основний — Liquid Glass (`src/styles/02-variants.css`, `data-variant="glass"`),
  база iOS — `01-base.css`. Cinema й iOS Classic лишаються як варіанти в Профілі.
- **Дати — лише `ymdLocal()`**, не `toISOString().slice(0,10)` (це день за UTC).
- **Стан глядача — у `localStorage` браузера** (ключ `meri.state.v1`). Сервера
  ще нема: монети можна «накрутити», тож це прототип, не продакшн.
- **Комітити лише свої файли:** `git commit -- <шляхи>`. Ніколи `git add -A`,
  `git add .` чи `git commit -a`.
- **Репо публічне** (`meri-ua/meri-ua.github.io`). Жодних ключів, токенів,
  особистих даних. Сайт: https://meri-ua.github.io/
- **Публікація — лише `npm run deploy`** і лише з моєї згоди в цьому чаті (скіл `/meri-deploy`).
- Мова коментарів, комітів і спілкування — українська.
